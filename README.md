# E-commerce Analysis in SQL

## Опис проєкту
Мета проєкту — побудувати SQL‑запит, який дозволяє аналізувати динаміку створення акаунтів та активність користувачів за емейлами (відправлення, відкриття, переходи). Додатково оцінюється поведінка користувачів у категоріях: **send_interval**, **is_verified**, **is_unsubscribed**. Це дає можливість порівнювати активність між країнами, визначати ключові ринки та сегментувати користувачів за різними параметрами.

## Згідно з технічним завданням фінальна таблиця має містити:

- **Категоріальні дані:**  
  `date`, `country`, `send_interval`, `is_verified`, `is_unsubscribed`

- **Агреговані дані (total):**  
  `account_cnt`, `sent_msg`, `open_msg`, `visit_msg`

- **Агреговані дані в розрізі країн:**  
  `total_country_account_cnt`, `total_country_sent_cnt`,  
  `rank_total_country_account_cnt`, `rank_total_country_sent_cnt`

## Структура SQL‑запиту
Запит складається з **6 CTE** та фінального запиту:

- **CTE1, CTE2** — формування основних метрик по акаунтах та емейлах  
- **CTE3** — об’єднання даних через `UNION ALL`, щоб уникнути втрати записів, яка могла б виникнути при використанні `JOIN`  
- **CTE4** — групування результатів після об’єднання для уникнення дублікатів у розрізі країн  
- **CTE5** — підготовка агрегованих показників для подальшого ранжування  
- **CTE6** — розрахунок рангів за допомогою віконної функції `DENSE_RANK()`
